How verification works here

leadcore does not check addresses itself. You run candidate addresses through an external verification service (ZeroBounce, NeverBounce, MillionVerifier, Bouncer, Apollo, …), then import the results here. A deliverable result becomes delivery-confirmed evidence and sharpens the firm's pattern; an undeliverable one is dropped from inference; catch_all is recorded but proves nothing.

  1. Export candidates to verify (CSV) — generated addresses not yet checked.
  2. Run that CSV through your verification service and download its results.
  3. Import the results below, then re-run leadcore infer (or it re-runs on next infer).
